# 归档说明

这里存放已经退出主运行链路的兼容入口、旧 Tk 功能窗口、历史构建产物和运行记录。

当前唯一用户入口是：

```text
启动.bat → webapp.py → pywebview + ui/
```

归档文件不应被主程序导入，也不应作为新功能的修改目标。保留它们只是为了旧快捷方式和历史代码追溯；确认不再需要兼容后，可以在单独的清理版本中删除整个 `archive/`。

运行时生成的 `__pycache__/`、锁文件和状态文件不属于源码；本次已将不在运行中的字节码缓存归入 `organization/20260726/bytecode-cache/`。当前仍被运行中程序使用的锁文件暂不移动。

每次整理的移动清单记录在对应的 `archive/organization/<日期>/README.md` 中。
