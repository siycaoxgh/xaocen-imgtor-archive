XAOCEN ImgTor v4.9.0 - Portable

直接双击 XAOCEN-ImgTor.exe 启动，无需安装 Python。

插件安装：
1. 在软件“设置”中查看插件目录；
2. 将 .xaocen-plugin 文件复制到该目录，或使用设置页的安装按钮；
3. 刷新插件状态，程序会自动校验 SHA-256 并解包。

包含插件：
- android_motion_photo.xaocen-plugin
- video_recorder_ffmpeg.xaocen-plugin

视频录制插件仍需要将 ffmpeg.exe 放入插件包对应目录，详见插件仓库说明。
插件包是 ZIP 格式的可读分发文件，安装后会解压为插件文件夹运行。

项目仓库：https://github.com/siycaoxgh/xaocen-imgtor
插件仓库：https://github.com/siycaoxgh/xaocen-plugin
